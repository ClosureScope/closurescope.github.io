# RhineLabUI 博客界面

首页移植自 [LBEILC/RhineLabUI](https://github.com/LBEILC/RhineLabUI)，保留三维阵列、玻璃文档抽取、解密、模型查看器、检索、声音与画质设置。访问网站后直接进入文章选择界面；开屏动画、进入确认、重播入口及开场动效选项已删除。模型加载期间只显示简短状态提示，声音在首次正常点击或按键时按浏览器策略解锁，不阻挡文章浏览。上游源码在 `site/src/rhine/`，资源在 `site/public/rhine/`，原项目 MIT 许可证、字体与声音来源说明一同保留。首阶段不接入上游 PWA 与壁纸宿主功能。

界面文案统一使用「文章」，后续新增提示、按钮和说明也遵循这一用词。

## 写文章

继续在 `posts/<分类>/*.typ` 写文章。新增、删除文件或分类后，`pnpm dev` 会重新编译并刷新；`pnpm build` 会重新扫描并生成发布版本。线上页面在重新构建部署后更新。

- 有文章的分类文件夹对应一个栏目；分类下直属 `.typ` 对应一篇文章。
- 分类和文章按现有构建脚本的文件夹名、文件名顺序排列。
- 分类数量和每类文章数量独立计算，没有五类、每类八篇的限制；空分类不显示。
- 左右切换分类，上下切换文章，首尾循环；每类记住本次选中的文章。
- 三维画面按视口复用模型，重复出现的模型属于循环展示；栏目计数显示真实数量。
- 收藏入口、收藏按钮、收藏快捷键和存储逻辑已删除。文章使用文件名 `slug` 定位，不再生成或展示文件编号；选择区、悬停提示、三维标签、详情和搜索结果均使用文章标题。
- 进入文章后，文件模型在原有三维场景中抽出、转正，原版场景中的阅读区域居中、放大，直接显示文章标题和正文，不再保留单独的左侧模型栏或白色卡片；顶部只保留返回、DIRECTORY 与独立阅读。文章信息、访问日志、格式元数据与模型查看入口已移除。独立阅读打开原有 `/posts/<slug>/` 地址。
- 左上角显示 ClosureScope；选择区直接以文章标题作为可点击的主标题，长标题自然换行。选择区的数据库、编号、权限标签和页脚授权、Powered By 字样已移除。

## 正文渲染隔离

现有 Typst 编译、`global.css`、网页字体和数学 SVG 处理保持不变。正文通过同源 iframe 载入现有文章页面，与三维界面的 CSS 隔离。内嵌阅读隐藏重复的站点页眉和返回链接，并将页面背景设为透明以衔接原版场景，保留原有文章标题、正文容器、样式和公式标记；独立文章页面保持原样。

阅读区域放在未缩放的浏览器坐标层，水平居中，最大宽度 1040px，高度扩展至顶部导航和底部间距之间。使用原有米色场景背景和分隔线，不增加卡片背景、边框、阴影或重复品牌栏；模型恢复原版的镜头构图。正文继续使用原有 17px 正文、小屏 16px 正文、41.23em 行宽、字体映射、SVG 基线与公式滚动；不会随着三维舞台缩放；正文跟随原有模型抽取与镜头动效揭示，返回时模型归位。顶部返回按钮与正文中的 Escape 返回文章选择，DIRECTORY 与 `/` 打开文章目录。

首页只接收 `slug`、标题、分类，不把全部文章 HTML 打入三维界面 JavaScript。正文仍是可独立访问的静态 HTML。

## 维护和验证

- `scripts/archive-index.mjs`：从现有文章元数据建立栏目、文章和位置索引。
- `site/src/rhine/data.ts`、`archive-loop.ts`：内容映射与循环；渲染池大小与文章身份分离。
- `scene.ts`：保留上游渲染，坐标重置支持任意列数及不同列长。
- `blog-reader.ts`、`blog.css`：阅读区域定位与界面适配，仅调整内嵌文档背景透明，不覆盖正文样式。
- `scripts/patch-rhine-rolling-number.mjs`：沿用上游对固定版本滚动文字依赖的测量修正；开发与构建前自动执行。

```bash
pnpm test:archive
pnpm build
pnpm test:math
pnpm test:archive-ui
```

`test:archive` 覆盖不同列长、七列、单篇栏目、四十篇栏目、反向循环、长期滚动坐标重置及旧版动效设置迁移。`test:archive-ui` 使用生产构建检查桌面与手机直接进入文章选择界面、旧设置兼容、动效切换和文章导航、搜索筛选、场景内阅读尺寸与模型抽取状态、末尾滚动、内嵌与独立页面正文及字体一致性；另以真实场景更新（仅跳过 GPU 栅格化）检查模型抬升、镜头移动、解密和归位。测试不启动或停止开发服务器。数学回归测试仍使用原有测试。
