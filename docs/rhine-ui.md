# RhineLabUI 博客界面

首页移植自 [LBEILC/RhineLabUI](https://github.com/LBEILC/RhineLabUI)，保留三维阵列、玻璃档案抽取、解密、模型查看器、检索、声音与画质设置。访问网站后直接进入文章选择界面；开屏动画、进入确认、重播入口及开场动效选项已删除。模型加载期间只显示简短状态提示，声音在首次正常点击或按键时按浏览器策略解锁，不阻挡文章浏览。上游源码在 `site/src/rhine/`，资源在 `site/public/rhine/`，原项目 MIT 许可证、字体与声音来源说明一同保留。首阶段不接入上游 PWA 与壁纸宿主功能。

## 写文章

继续在 `posts/<分类>/*.typ` 写文章。新增、删除文件或分类后，`pnpm dev` 会重新编译并刷新；`pnpm build` 会重新扫描并生成发布版本。线上页面在重新构建部署后更新。

- 有文章的分类文件夹对应一个栏目；分类下直属 `.typ` 对应一篇文章。
- 分类和文章按现有构建脚本的文件夹名、文件名顺序排列。
- 分类数量和每类文章数量独立计算，没有五类、每类八篇的限制；空分类不显示。
- 左右切换分类，上下切换文章，首尾循环；每类记住本次选中的文章。
- 三维画面按视口复用模型，重复出现的模型属于循环展示；栏目计数显示真实数量。
- 收藏入口、收藏按钮、收藏快捷键和存储逻辑已删除。文章使用文件名 `slug` 定位，不再生成或展示文件编号；选择区、悬停提示、三维标签、详情和搜索结果均使用文章标题。
- 正文显示在档案详情的「正文」页签；「READ / 独立阅读」打开原有 `/posts/<slug>/` 地址。
- 左上角显示 ClosureScope；选择区直接以文章标题作为可点击的主标题，长标题自然换行。选择区的数据库、编号、权限标签和页脚授权、Powered By 字样已移除。

## 正文渲染隔离

现有 Typst 编译、`global.css`、网页字体和数学 SVG 处理保持不变。正文通过同源 iframe 载入现有文章页面，与原界面的 CSS 隔离。仅在内嵌阅读时隐藏重复的站点页眉和文章标题；正文容器、样式和公式标记保持原样，独立文章页面仍显示原来的页眉和标题。

iframe 放在未缩放的浏览器坐标层，跟随原文档区域定位。这样三维界面的舞台缩放不会缩放正文文字，文章继续使用原有的 17px 正文、小屏 16px 正文、字体映射、SVG 基线与独立公式滚动。详情左上角的返回按钮与阅读区域内的 Escape 均可返回阵列。

首页只接收 `slug`、标题、分类，不把全部文章 HTML 打入三维界面 JavaScript。正文仍是可独立访问的静态 HTML。

## 维护和验证

- `scripts/archive-index.mjs`：从现有文章元数据建立栏目、文章和位置索引。
- `site/src/rhine/data.ts`、`archive-loop.ts`：内容映射与循环；渲染池大小与文章身份分离。
- `scene.ts`：保留上游渲染，坐标重置支持任意列数及不同列长。
- `blog-reader.ts`、`blog.css`：阅读区域定位与界面适配，不注入文章文档样式。
- `scripts/patch-rhine-rolling-number.mjs`：沿用上游对固定版本滚动文字依赖的测量修正；开发与构建前自动执行。

```bash
pnpm test:archive
pnpm build
pnpm test:math
pnpm test:archive-ui
```

`test:archive` 覆盖不同列长、七列、单篇栏目、四十篇栏目、反向循环、长期滚动坐标重置及旧版动效设置迁移。`test:archive-ui` 使用生产构建检查桌面与手机直接进入文章选择界面、旧设置兼容、动效切换和文章导航；它不启动或停止开发服务器。数学回归测试仍使用原有测试。
